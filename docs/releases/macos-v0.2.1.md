## 云之彼端 Home 0.2.1

修复 0.2.0 发布包在下载、解压后无法启动的问题。

- 使用 Xcode 构建后端生成资源访问代码，正确读取 App 内的字体、模型和插件资源，避免依赖 CI 机器上的构建目录。
- 打包后严格校验代码签名；CI 与发布流程增加独立目录启动验证，临时隐藏构建缓存，确认 App 能正常渲染界面后才发布。
- 保留 Home Assistant 绑定、钥匙串令牌、多台空调、房间映射与跨 App 状态同步。升级不需要重新绑定设备；macOS 可能再次询问钥匙串访问授权。

下载 `YunHome-0.2.1.zip`，解压后将 `YunHome.app` 放入“应用程序”。需要 macOS 14 或更高版本。App 使用 ad-hoc 签名，尚未进行 Developer ID 签名与 Apple 公证。
