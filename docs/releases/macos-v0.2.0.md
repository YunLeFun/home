## 云之彼端 Home 0.2.0

这次更新让 Home 与云空调 CuteAC 共用 Home Assistant 绑定，连接真实空调，并在两个 App 中同步设备状态。

### 新增

- **Home Assistant 接入**：在原生 App 中查找 HA、测试连接并批量绑定 `climate` 空调实体；可通过 HA 的小米官方集成接入米家空调。访问令牌保存在 macOS 钥匙串中。
- **多台空调与房间映射**：为客厅、主卧、次卧等房间分别绑定和切换空调，也支持自定义房间。侧栏、快捷控制、桌面空调和遥控器显示当前控制目标。
- **跨 App 状态同步**：Home 发布不含令牌的共享绑定目录，CuteAC 0.4.0 可复用已有设备与钥匙串凭据。两个 App 各自保存选择的设备，通过 HA 自动同步开关、模式和温度。

### 改进

- 按设备回报的温度范围与步进调温，支持 0.5°C；兼容未提供实体温标、但 HA 系统使用摄氏度的设备。
- 真实室温使用空调传感器读数；断线、令牌失效或温标不支持时禁用控制。
- 修复本机 `homeassistant.local` 的 IPv4/IPv6 解析及恢复逻辑。
- 中文应用名统一为“云之彼端”，保留已有存档与绑定。

### 使用与验证

先在 Home 中完成 HA 绑定，再打开 CuteAC 0.4.0 选择对应空调。首次共用钥匙串令牌时，macOS 可能要求手动授权；房间映射保存在本机。

已通过三台小米空调的绑定与状态读取验证，并完成次卧空调开关、调温和 CuteAC → Home 自动同步联调；测试后恢复了原设置。

下载 `YunHome-0.2.0.zip`，解压后打开 `YunHome.app`。需要 macOS 14 或更高版本。本版使用 ad-hoc 签名，尚未进行 Developer ID 签名与 Apple 公证。
